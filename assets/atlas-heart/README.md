# Quiet Atlas heart illustration

`heart.webp` is an original OpenAI ImageGen illustration generated on 2026-10-28
for the owner's selected Home design, converted to transparent WebP (768×1152).
It is decorative illustrative anatomy, not a clinical reference or labeled
teaching diagram. The interactive physiological heart remains available through
Explore in 3D. No licensed question or reference-library image was used.

The Home workflow's eye and message-circle icons use Lucide icons (ISC),
retrieved from https://github.com/lucide-icons/lucide on 2026-10-28.
Their upstream license is included in `LUCIDE-LICENSE`.
